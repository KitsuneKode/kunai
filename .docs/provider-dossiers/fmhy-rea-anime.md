# FMHY starred anime sites — backend family vs Kunai

> Agent-facing (L3). **Never linked from published docs.** Parent intake: `.docs/provider-dossiers/fmhy-starred-parity.md` (not edited by this pass). September Anikoto note: `.docs/provider-dossiers/anikoto-candidate.md` describes `anikoto.cc` and is not the current FMHY host.

## Scope and method

- **Question:** Which FMHY-starred anime sites are a new direct source, and which are skins of AllManga (mkissa), HiAnime, or Miruro?
- **Date:** 2026-11-12. Star list taken from `https://fmhy.net/video` (**HTTP 200**, saved HTML about 305 KB). Every assigned href below is present on that page.
- **REA:** `rea` is not on PATH. REA MCP is not connected. No `rea setup` and no engine install. JavaScript application graph, module identities, and feature traces are **unknown**. Evidence is curl plus string inspection of saved HTML and JS.
- **Fetch:** `curl -4 -L --compressed --http1.1`, Chrome 131 UA, no cookies, max 25s, no Cloudflare or Turnstile bypass, no video segments, no playlist or file download, no decryptor, no session-token harvest. Keys, JWTs, and site-key values are omitted below even when a bundle contained them.
- **Captures:** `.reference/experiments/scratchpads/provider-fmhy-rea-anime/captures/`.
- **Kunai match strings:** `api.mkissa.net`, `cdn.mkissa.net`, `x-aa-boot`, `hianime.at`, `zokoanime.video`, `aniwatchtv.uk`, `/api/theme/episode/list`, `miruro.cx`, bee/kiwi provider names. `animegg` and kickassanime (`kaa`) are mentioned only where a starred bundle names them.

**Scores:** **high** = new direct media, or a JSON source list Kunai does not already speak, with a reproducible request. **mirror** = same backend as AllManga, HiAnime, or Miruro. **hold** = iframe or embed. **unknown** = fetch failed, or the saved bundle did not contain the API.

Labels: **Observation** is a fetched artifact. **Inference** is a reading of that artifact. **Unknown** includes every REA gap.
