## 4. Threat model (compact)

**Trust boundaries:** provider metadata→UI · provider data→mpv/yt-dlp argv+IPC · remote files→FS · `kunai://`/share codes→session · GitHub releases→self-update · config/vault→secrets · relay→upstream HTTP · remote text→stderr/logs.
**Top attack surfaces:** ① raw `<Text>` producers (C1-OSC/OSC-8/SGR) ② logs.txt/stderr stored payloads ③ `security -w` argv ④ config scalar passthrough (self-inflicted) ⑤ `kunai://` `q`/`n` pre-confirmation render ⑥ relay-omitted providers silently direct-fetching (privacy expectation, not exploit).
**Strongest defenses (verified):** relay SSRF stack (pinned DNS, redirect revalidation, credential strip, metadata-only, byte caps); updater chain; atomic-write + secret vault; argv-everywhere (no shell strings); analytics consent contract.
