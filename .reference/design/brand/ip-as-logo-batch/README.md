# Kunai IP-as-logo batch 1 — superseded

**This batch is retired.** Its six masters (`kunai-ip-A*/B*/C*.png`) were deleted
once the Kanna v1 sheet landed; nothing generates from them any more.

They were three separate _directions_ — Operator, Courier, Watcher — drawn so a
human could pick one. All three shipped instead, which gave the mascot three eye
treatments, three ear silhouettes and a chest blaze that appeared, vanished and
came back. It never read as the same animal twice, and that is the problem the
Kanna sheet exists to fix.

What replaced them, and why the method worked, is in
[kanna-pose-sheet.md](./kanna-pose-sheet.md) and
[../kanna-art-brief.md](../kanna-art-brief.md). The one rule worth carrying
forward: **generate a model sheet as a single image.** Six views in one pass is
what holds a character together; six separate prompts gives six cousins.

The locked palette is unchanged and still governs every draw:

| ------------ | --------- | ------------------------- |
| IP 1 · fur   | `#ff8fb0` | body                      |
| IP 2 · cream | `#ffc6d8` | muzzle, inner ears, chest |
| background   | `#1c1620` | tile; reused for eyes     |
