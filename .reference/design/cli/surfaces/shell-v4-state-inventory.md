## Global `Esc` Unwinding Ladder (Shell v4 Contract)

Every surface must route `Esc` through one shared reducer (`resolveEscStack`) in this strict priority order — `Esc` **never** confirms, **never** starts playback, and **never** jumps two layers on one press:

1. **Active text edit** (Settings input banner, playlist rename) → cancel edit, keep value unchanged.
2. **Armed `ConfirmStrip` / `SourceChoiceStrip`** (History, Library, Downloads, Up Next, Notifications, Playlists) → disarm strip, stay on surface.
3. **Command palette (`/`)** → close palette, restore prior focus & draft.
4. **Type-ahead suggestion band** (Browse) → dismiss band for current draft, stay in search input.
5. **Active filter / search query** (Picker filter, History/Library `Ctrl+F`, Settings `/`, Browse `Ctrl+F` → filter chips → non-empty query) → clear filter/query, stay on surface.
6. **Submenu / child sheet** (Settings submenu, Details sheet, Library title detail, Notification action menu) → return to parent surface with selection preserved.
7. **Top root overlay / picker** (Tracks, Episodes, History, Library, Downloads, Up Next, Notifications, Diagnostics, Help, Guide, Settings, Calendar) → close overlay, return to underlying surface.
8. **Cancellable resolve / loading** → abort in-flight request, return cleanly to previous results (never a dead screen).
9. **Post-play** → return to previous Search results (never quit the app on `Esc`).
10. **Browse home (empty query)** → no-op (never accidentally exit the shell; quit stays explicit `Ctrl+C` or `/quit`).
