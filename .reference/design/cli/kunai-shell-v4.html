Kunai · ❀ Shell v4 — Every Surface, Every State

Supersedes piecemeal screen tweaks with one state-complete visual system on the live Ember Dusk Sakura tokens (packages/design/src/tokens.ts). Every surface below was audited against live L2 agent:drive captures at 120×32, 54×25, 40×20, and KUNAI_PLAIN=1. Paired with surfaces/shell-v4-state-inventory.md (112 surface×state rows), 02-state-ux.md (consistency rules), and shell-v4-implementation-map.md (18 ranked changes + giant-file shrink plan).

Scope boundary: Onboarding (install, setup wizard, first Browse intro, first stream card) is owned by a separate track and is not redesigned here; handoff seams into Home/Browse and Settings are noted where relevant.
1 · Loading Grammar
◌ verb… + static slot
Header says ◌ loading… (never ● ready). Body uses one LoadingState in a reserved slot. Multi-step rail stays 1:1 synced with headline. Plain mode suppresses 1s tick redraws.
2 · Error Grammar
× What · Why · 1 key
Static (zero animation). Header switches to ● issue. Body names what failed, what was preserved, and one primary recovery key (▌ ↵). Diagnostics stays behind [d]. Footer swaps to recovery keys only.
3 · Empty Grammar
· Empty · Next verb
Names what is empty and the one action that populates it. Never prints contradicting 🦊 empty for now above live rows. Empty lists strip dead row verbs ([enter], [x], [m]) from ShellFooter.
4 · Focus-Owner Grammar
▌ or ⌕ — never both
Exactly one owner per frame: text input owns rose ⌕ + rule; list owns column-0 ▌ + accentFill; two-pane keeps passive ▸; armed ConfirmStrip takes focus & swaps footer to [y] confirm [esc] cancel.
