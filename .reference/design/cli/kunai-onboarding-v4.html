0 · Install

The installer's last lines are the first instruction a stranger reads. They now end on the one command that plays something, and they name a player problem before Kunai is ever launched.

2 · First Browse — ready to type

Setup ends in Browse, not on a summary screen. The cursor is in the search field; picks sit underneath as something to choose, never as something that swallows the first keystrokes. Setup saved rides the shell's transient row for ten seconds and then goes.

Warm cache · picks already on disk

changed in v4

Was: focus on the first pick, so typing did nothing visible and Enter opened a recommendation. Now picks that load on their own never take the field; ↓ steps into them. The hint under the field names both ways on.

Cold cache · picks still loading

new in v4

Was: a static “welcome to kunai” screen that accepts no typing until the network answers. Now Browse mounts at once, the field is live, and three commands are offered while the picks load. When they land they replace this block without moving the field. Reduced motion holds the petal still.

Picks never arrived — offline, or the catalog is down

new in v4

Was: “No recommendations right now. Finish something from history, then retry /recommendation.” — advice a first-run user cannot follow. The new copy does not claim a cause it cannot know, and does not point a fresh install at /library.
